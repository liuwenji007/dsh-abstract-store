# AGENTS.md

Instructions for coding agents working in this repository.

## The pipeline

Three layers, three owners:

1. **Facts** live in `data/snapshot.json`. It is generated from the upstream
   [awesome-dsh-plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin)
   checkout by `npm run sync -- --upstream <dir>`. Never hand-edit it; fix the
   upstream entry and re-sync.
2. **Editorial** lives in `data/curation.json`. One decision per snapshot slug.
   This is the only hand-edited data file. Scores are derived from its
   `absurdity` / `emotion` / `craft` fields; never store a `score`.
3. **UI** lives in `src/client.js` (plain React, no JSX, no imports). The
   installed artifact is the committed `client.js`, generated by
   `npm run build`. Never edit `client.js` directly.

The host loads the UI as one classic script through
`window.__ModuleLoader__.load`, which is why `src/client.js` must stay plain
statements; the build concatenates it into the loader factory.

## Before claiming a change is done

```sh
npm run check   # validate -> build -> node --check
```

Then confirm `git diff` contains the rebuilt `client.js`. CI fails when the
committed artifact does not match a fresh build.

## Rules that are easy to get wrong

- Every snapshot slug needs exactly one curation decision, and every curation
  slug must exist upstream. `npm run validate` enforces both.
- Verdicts: `zh` ≤ 40 characters, `en` ≤ 110; both filled; English translates
  the same claim. Excluded entries need `reason` instead.
- Inclusion is editorial, not a whitelist: exclude ordinary entertainment and
  utilities with no absurd premise, and say why.
- The tab is a Client-only contribution to `plugins.tab`. It must not fetch,
  poll, read sessions, or create its own page shell; the host page owns scrolling.
- Install goes through the host's `install(target)` owner prop. Do not shell out,
  and do not invent install commands for subdirectory plugins without a package.
- The UI uses `--dsw-alias-*` / `--dsw-radius-*` theme tokens with fallbacks;
  literal colors belong to the icon only.
